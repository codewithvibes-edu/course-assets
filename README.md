# Code With Vibes — Course Assets

Downloadable materials for the [Code With Vibes](https://codewithvibes.com)
builder course: starter repos, prompt libraries, templates, and printable
references, one folder per module.

Every folder under `assets/` maps to a course module and has its own README
explaining what is inside and how to run it.

## Layout

| Folder | Module | What it is |
| --- | --- | --- |
| `assets/m1-model-selection/` | M1 | Model selection one-pager (printable PDF + generator) |
| `assets/m2-prompts/` | M2 | Prompt template library (markdown + JSON) |
| `assets/m3-routing/` | M3 | Routing config template + cost-modeling sheet |
| `assets/m4-data-sources/` | M4 | Data source inventory, vendor sheet, license checklist |
| `assets/m5-ingestion-starter/` | M5 | Ingestion pipeline starter (files, API pull, webhooks, queue) |
| `assets/m6-cleaning/` | M6 | Cleaning + dedup + schema + chunking reusable module |
| `assets/m7-rag-starter/` | M7 | RAG starter repo with eval loop |
| `assets/m9-tools/` | M9 | Tool definitions library |
| `assets/m10-multi-agent-starter/` | M10 | Multi-agent starter (supervisor + specialists) |
| `assets/m11-mcp-starter/` | M11 | FastMCP server starter |
| `assets/m12-knowledge-base/` | M12 | Knowledge-base note templates + anti-bloat rules |
| `assets/m13-eval-harness/` | M13 | Eval harness starter (deterministic, model-graded, human) |
| `assets/m14-cost-latency/` | M14 | Cost / latency / reliability tracking |
| `assets/m15-guardrails/` | M15 | Guardrails module + prompt-injection corpus |
| `assets/m16-capstones/` | M16 | Capstone starter repos (4 tracks) |
| `assets/m17-agent-workflow/` | M17 | Coding-agent workflow templates |

## Using the code

Python starters each ship a `requirements.txt`; create a virtualenv per
starter and install from there. Pricing numbers anywhere in these materials
are dated snapshots — verify against your provider's pricing page before
relying on them.
