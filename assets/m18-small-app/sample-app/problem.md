# Problem: snip

**One user:** me, a person who lives in a terminal and re-googles the same
commands weekly.

**One repeated job:** capture a command or one-liner the moment I finally
get it right, and find it again later without leaving the shell.

**One visible result:** `snip search ports` prints the lsof incantation I
saved last month, in under a second, with the tags I filed it under.

**Non-goals:** no sync between machines, no encryption, no shell-history
integration, no editor plugin, no colors. Version one keeps text in a JSON
file and gets out of the way.

Demoable in under two minutes: add two snippets, list them, search one,
delete one. Done.
