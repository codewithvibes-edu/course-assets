# Daily_Driver_Ops_Kit templates

The learner-held artifact tree for m25. Copy this folder to start yours;
every file below gets filled by a specific lesson. The canonical files
describe inputs, outputs, owners, permissions, side effects, and recovery
WITHOUT product syntax; anything harness-specific you generate goes under
evidence/, labeled with harness, recipe version, and test date. Neutral
contract in the kit, volatile syntax in dated recipes: that split is what
makes this kit survive your next harness.
