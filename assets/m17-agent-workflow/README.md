# Agent workflow starter kit (Module 17)

Two files that anchor the working-with-coding-agents workflow from Module 17.

## Files

- `CLAUDE.md.template` — a project-brief template for your coding agent. Copy
  it into your repo root, fill in every section, and update it every time you
  catch the agent doing something you had to correct. Most coding agents read
  a project instructions file at the start of a session (the filename varies
  by tool); the structure works for any of them.
- `review-checklist.md` — the one-pass review checklist to run on every
  agent-written change before you commit it. Keep it next to your terminal
  until the habits stick.
