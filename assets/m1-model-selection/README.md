# Model selection one-pager (Module 1)

A single-page printable reference: the four levers that drive model choice,
the five model classes, and the back-of-the-napkin decision flow for picking
a class. Designed to live on a desk or pinned in a workspace.

## Files

- `one-pager.pdf` — the printable one-pager (US Letter, single page)
- `one-pager.html` — the source template the PDF is generated from
- `generate.sh` — regenerates the PDF with headless Chrome/Chromium

## Regenerating

```bash
./generate.sh
```

Requires Chrome or Chromium on your PATH or in the default macOS location.

Model names in the classes table are a 2026 snapshot and rotate fast; the
classes themselves are what is stable. Module 3 of the course covers the
full routing treatment.
